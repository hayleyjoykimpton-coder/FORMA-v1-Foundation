# CRACKER Instagram carousel

Seven 1080×1350 (4:5) slides for the Life & Soul Christmas Cracker app.

## Files

- `index.html` — editable slide layout
- `out/slide-01.png` … `slide-07.png` — ready to upload
- `render.mjs` — rebuild PNGs after copy or layout changes

```bash
pnpm exec playwright install chromium
node marketing/instagram/render.mjs
```

## How to post

1. Instagram → New post → select all 7 PNGs in order.
2. Keep 4:5 crop. Do not letterbox.
3. Caption idea:

   Christmas Cracker 2026 is in the app.
   Train with Jess. Fuel with Naomi. Stay connected with your club.

   Open formafigure.com → sign in → Add to Home Screen.

   12 October – 22 November · Life & Soul

4. Stories: you can also post slide 01 and slide 07 as a pair with a link sticker to formafigure.com.
